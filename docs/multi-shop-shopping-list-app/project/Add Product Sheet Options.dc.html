FreshCart · Add product sheet
What it needs, then three ways to show it
ALWAYS · ALREADY FILLED
Name
Typed in the FAB before the sheet opens. It's a confirmation, not a question, so it can be big but quiet.
ALWAYS · DEFAULTED
Shop
Defaults to the open tab. It's the one real decision on the sheet, so it gets the most visual weight.
SOMETIMES · DEFAULT 1
Amount
Usually 1. A compact stepper is enough, with no presets. It should take one line, not a section.
RARELY · EMPTY
Note
Most items never get one. Hide it behind "Add note" so it doesn't make every sheet taller.
