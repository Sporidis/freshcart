07 — Motion

Six timings

TokenmsCurveUsed for
micro120easeOutPress states, opacity flips
quick180easeOutCubicChip selection, tint, dismissals
standard260easeOutCubicTabs, drawer, list reflow
bouncy340easeOutBackCheck fill, new row, FAB
sheet380 / 220easeOutQuint / easeInCubicBottom sheets in / out
celebrate900spring 180 / 14List-complete card only

The rule that gives the app its character: overshoot only what the user did. Their own taps get easeOutBack; remote edits, syncing and loading stay on plain easeOutCubic. AppMotion.duration(context, …) already honours the OS reduce-motion setting.

08 — House rules

Do / don't

Do

Read colour from Theme.of(context), never a literal hex in a screen.
Put the shop colour on the accent, the list content in ink.
Give every destructive action an undo, except deleting a list.
Show structure while loading — skeletons, not spinners.
Let the user shop offline; sync is the app's problem.

Don't

Don't tint the whole app to the shop colour — only accents.
Don't name shop colours after retailers in code.
Don't use labelText; labels sit above the field.
Don't animate remote changes while the user is mid-gesture.
Don't add a radius, duration or grey that isn't in this document.
