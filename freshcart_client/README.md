# freshcart_client

The Dart client for `freshcart_server`, **generated by Serverpod. Do not hand-edit.**

Regenerate it from `../freshcart_server` after changing a model or an endpoint:

```bash
serverpod generate
```

Its types are DTOs. In the app they are used **only** in a feature's `data/` layer and
mapped to `freshcart_domain` entities there (`X.toDomain()` / `X.toDto()`). CI fails if
this package is imported from `application/` or `presentation/`.
